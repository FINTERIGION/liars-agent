# 骗子酒馆 AI 决策智能体训练与评测平台 (`liars-agent`)

面向对手适应的语言模型训练与评测系统（支持四人对局规则引擎、严格观测隔离、5 类参数化策略对手池、小型分类器基线、Qwen3.5-9B LoRA 监督微调与多次续玩策略改进、座位轮换配对 Bootstrap 评测及 Gradio 决策复盘工作台）。

## 当前固定游戏规则（`liars_bar_research_v2`）

1. **胜负：** 四人开始，死亡者淘汰，最后一名存活玩家获胜。打光手牌只退出当前小局行动，不代表整场胜利。
2. **牌与发牌：** Q/K/A 各 6 张，JOKER 2 张，共 20 张。每小局重新洗牌，存活玩家各拿 5 张，多余牌不使用。随机选择 Q/K/A 中一种目标牌，可与上一小局相同，小局内保持不变。JOKER 是万能真牌，无额外惩罚效果。
3. **行动顺序：** 第一小局随机先手，此后按座位顺序循环，跳过死亡和空手玩家。只能选择当前合法出牌或质疑动作，没有摸牌或主动跳过。
4. **出牌：** 暗置打出自己手中的 1～3 张，声称全部为目标牌。张数如实公开，可以全真、全假或真假混出，不要求与上一手张数相同或递增。第一手只能出牌。
5. **质疑：** 只翻开最近一次出牌，不检查此前累计的牌。只要有一张既非目标牌又非 JOKER，就是诈唬，由出牌者开一枪；全部为真则质疑者开一枪。下一名玩家继续出牌后，不能回头质疑更早的一手。
6. **空手退出：** 打光手牌者不再出牌或质疑；刚出的最后一手仍可被下家质疑，若是假牌则仍可受罚。下家继续出牌后，该空手玩家一直被跳过，直到下一小局重新发牌。
7. **强制质疑：** 存在上一手且仅当前行动玩家还有牌时，当前玩家必须质疑，不能继续出牌。适用于两人、三人、四人仍存活的情况。例如 A 刚打空、其余人已空手、仅 B 有牌且轮到 B，则 B 必须质疑 A；若还有其他玩家有牌，B 可以选择继续出牌。
8. **左轮：** 每人 6 个弹膛、1 发实弹，开局随机确定实弹位置，整场不重置。每次受罚开一枪，击中实弹即淘汰；仍存活且已开枪 k 次者下一枪致死率为 1/(6-k)。受罚不等于必然死亡。
9. **换小局：** 每次质疑结算一次开枪后结束小局，无论是否有人死亡。若剩余多名玩家，重新发牌，由受罚者（若存活）或其下一名存活玩家先手；开枪次数跨小局累计。只剩一人时整场结束。不设置额外的 60 步结束或判负规则。
10. **信息：** 玩家只能看到自己的手牌/本小局出过的牌、目标牌、公开行动、各人手牌数量/存活状态/开枪次数，以及过往质疑亮牌与结算。其他人的底牌、未翻开出牌、未发出的牌和所有实弹位置（包括自己的）均不可见。完整历史模式提供全部过往小局公开结算；全量真值复盘仅整场结束后开放，新局清空旧复盘，各浏览器会话独立。

[规则规格 YAML](configs/rules_default.yaml) 是固定规则的说明，**不是运行时配置入口**；修改它不会切换玩法。原先未接入的强制质疑开关和 60 步限制已移除。实际执行见 [规则引擎](src/liars_agent/engine/state.py)，模型使用同一套 [规则提示](src/liars_agent/agents/prompt_builder.py)。对手策略参数、训练评分和历史消融不改变游戏规则。

## 历史示例与新数据

仓库原有 `outputs/dataset/`、`outputs/models/`、`outputs/replays/`、`outputs/figures/` 及 `outputs/experiment_summary.json` 是旧版本的模拟示例，不能作为当前规则数据或真实 Qwen 训练/评测结果。旧样本中的提示、动作和历史原样保留以便追溯，已加 `historical_example: true` 标记；数据切分/训练入口会拒绝这些样本，使用当前规则时必须重新生成。旧模型元数据和实验汇总也明确标记为历史示例。

当前发布版本仍保留原有模拟训练和模拟 LLM 演示代码，以下流水线命令用于演示，不产生真实模型实验结论。新演示产物写入独立的 `outputs/runs/rules_v2_demo/`，不覆盖旧示例。真实实验代码另行开发，不包含在此次规则更新中。

## 一、核心特性与架构

1. **确定性研究用规则引擎 (`src/liars_agent/engine/`)**：
   - 标准 20 张牌组（`Q`×6、`K`×6、`A`×6、`JOKER`×2），4 人各发 5 张牌，单次出牌 1~3 张。
   - 强制质疑：存在上一手出牌且除当前行动玩家外其余存活玩家均已空手时，当前玩家必须质疑上一手，不能继续出牌；两人残局上家打空手牌也属于该情形。例如 A 刚打空、C 已空手，仅 B 还有牌且轮到 B 时，B 必须质疑 A。
   - 空手退出：打光手牌者不再出牌或质疑；其刚出的牌仍可被下家质疑，若下家继续出牌，则该玩家被跳过，直到下一小局重新发牌。
   - **严格信息隔离 (`PlayerObservation`)**：模型仅接收自身手牌与公开历史，绝不接触其他玩家手牌或左轮实弹位置。
   - **100% 可复现回放 (`replay.py`)**：支持 JSONL 轨迹导出与 SHA-256 指纹回放一致性校验。
2. **多策略对手池与智能体 (`src/liars_agent/agents/`)**：
   - **训练可见对手池 (Seen Pool)**：`HonestConservativeBot`（诚实保守型）、`AggressiveBlufferBot`（激进诈唬型）、`CardCounterBot`（记牌精算型）。
   - **未见测试对手池 (Unseen Holdout Pool)**：`ParanoidHunterBot`（多疑猎手型）、`ChameleonAdaptiveBot`（变色龙切换型）。
   - **基线与主模型**：`SmallClassifierBot`（12 维统计特征小型分类器）、`LLMAgent`（支持 Qwen3.5-9B 零样本、LoRA-SFT、LoRA-RS 及 Tinker API 远端采样，内置非法动作回退与成本审计）。
3. **训练数据合成与按局切分 (`src/liars_agent/training/`)**：
   - 基于混合对手博弈与蒙特卡洛多次续玩（Rollout）收益筛选合成高质量 SFT 样本。
   - 严格按完整对局 (`game_id`) 划分训练/验证/测试集，防止同局步间泄漏。
4. **统一评测工作台与四类核心分析图 (`src/liars_agent/evaluation/`)**：
   - **座位轮换配对评测 (`Duplicate Block Protocol`)**：每个 Block 固定发牌与实弹种子，轮换 4 个座位，报告配对 Bootstrap 95% 置信区间。
   - 自动导出四类核心 SVG 矢量分析图（胜率及 CI 对照图、历史消融图、风险与手牌分层诊断热力图、信念校准曲线与四维行为画像图）。

## 二、快速开始

### 1. 运行系统正确性单元测试
```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

### 2. 运行端到端数据生成、训练、配对评测与图表生成流水线
```bash
PYTHONPATH=src python3 scripts/run_full_pipeline.py --output-dir outputs/runs/rules_v2_demo --eval-blocks 45
```
运行完成后将在指定新目录下生成 `dataset/`、`models/`、`replays/`、`figures/` 与 `experiment_summary.json`。这些仍为模拟流水线输出。

### 3. 启动交互式对局与决策复盘界面
```bash
PYTHONPATH=src python3 -m liars_agent.ui.app --port 7860
```
