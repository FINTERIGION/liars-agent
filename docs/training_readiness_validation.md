# v3 训练前修正验收

日期：2026-11-14。监督版本：`empirical_all_answers_weighted_actions_v3`。

本次完成本地实现、残局补充、独立诊断集接入与离线检查。未登录 Tinker，未创建真实训练或采样会话，付费模型调用为 0。SDK 测试中的响应、更新和保存来自明确的内存替身，不属于真实模型实验。

## 已修正的训练路径

- 动作监督和候选验证统一截止首个 assistant EOS，包含 EOS、排除其后的模板分隔符。缓存的真实 Qwen tokenizer 中，`<|im_end|>` 为 248046，其后换行 198 不再计算损失或 checkpoint 分数。全答案 `w/k`、状态归一化及信念单 token 监督不变。
- sampling client 显式传入 `RetryConfig(enable_retry_logic=False)`。真实安装 SDK 的内存失败注入覆盖动作采样和信念打分：结果失败后没有以新请求编号重提交，未结算的预算预留仍保留。同请求的底层传输重试保持 SDK 行为。
- 从状态 checkpoint 初始化时，在 preflight 前核对来源基础模型、监督协议和完整 LoRA 配置：rank、attention、MLP、unembedding。缺失或不一致均拒绝；元数据不再将请求配置冒充实际继承配置。
- 固定验证子集每任务最多 64 条，在步骤 0、50、100 做早期诊断；子集身份和指标保存于 `training_diagnostics.json`。正式 checkpoint 仅按每轮完整验证集的动作集合 NLL 选择，不将不同验证集合的 loss 混比。
- `sft_trial` 提供有限步数小试，默认 5 步，诊断步骤为 0、5，使用正式三轮的学习率计划。只生成 `trial_metadata.json`，不生成正式 adapter，也不将正式 SFT 标为完成。`estimate_trial` 可在无模型会话时精确估算该计划。

## 独立检查与复查

原检查集保持 148 条观测、21 个来源局，其中 133 条有待回应声称，15 条无声称。观测和标签联合 SHA-256 为 `affb8b11a036ac000b97c000202250cb3fedc44142ff4f78f4e55287ebff27c7`。

独立检查已接入主 `evaluate` 和单独 `endgame_evaluate` 阶段。模型只收到合法观测；输出分别统计原生动作合法率、执行动作合法率、强制质疑遵从率、回退率和原生信念校准，并提供场景／存活人数分组及有效样本数。无声称不进行信念打分，模型概率不被回退策略概率覆盖。缓存绑定检查集及模型配置，匹配复用、错配拒绝。

本次实际运行了分类器和记牌规则两种本地基线：各 148/148 原生动作合法、60/60 强制质疑遵从、0 次回退，信念有效样本各 133。已用会抛错的动作调用替身验证缓存再次运行不调用策略。此结果只说明这两种本地基线通过所测规则边界；无自由动作最优标签，不报告最优动作准确率，也不作为 Qwen 的模型结果或自然分布胜率。

全量离线测试为 **161 passed、101 subtests passed**。覆盖 EOS 后缀排除、全部答案权重守恒、早期验证与完整验证分离、有限步数小试、LoRA 不匹配提前拒绝、SDK 单次提交与失败预算、残局替换和保持测试集独立、模型／回退信念归属，以及缓存复用。独立代码复查还重跑了两个新增教师报告的前 8 条轨迹，与保存奖励一致；修改私有标签和游戏标识不改变模型输入或动作监督。

真实 tokenizer 全量验收已通过：20,000 条样本、14,574 个可接受动作答案（train 11,609／val 1,465／test 1,500），以及验证集全部 10,729 个合法候选。所有动作目标截止首 EOS，信念单标签权重为 1，每轮覆盖全部训练状态的全部答案；SDK float32 掩码总状态权重为 8000.000171996653，与理论 8000 在容差内一致。最长完整序列 6,258 token，低于 16,384 上限。独立核验器与费用估算的 16 个计数字段逐项完全相符，包括早期验证样本身份和执行计划。
