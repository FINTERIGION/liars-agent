## 数据与训练目标

源目录为 `outputs/runs/selfplay_v2_20261113_01_quality`，新目录为 `outputs/runs/selfplay_v2_20261113_01_quality_supervision_v1`。源文件哈希、观测、原始单答案、信念标签和完整对局划分保持不变。新目录另存候选得分、可接受答案集合和损失权重；原目录保留。

| 划分 | 动作样本 | 并列最高分 | 唯一最高分且小分差 | 其余动作 | 信念样本 |
| --- | ---: | ---: | ---: | ---: | ---: |

| test | 1,000 | 360 | 139 | 501 | 1,003 |

- 并列集合只包含教师经验均值的最高分动作，浮点容差为 `1e-12`。同一观测按固定种子排列答案，每个 epoch 轮换一个；同一 epoch 的补齐重复和恢复使用相同答案。
- 唯一最高分且与次高分差不超过 0.05 时，原始权重为 0.5；其余动作原始权重为 1。训练动作权重均值为 0.924875，归一后分别约为 0.540614 和 1.081227，总有效权重为 8,000。信念权重保持 1。
- 94 条训练样本有超过 3 个并列答案（69 条有 4 个、25 条有 5 个）。默认 3 epochs 不保证遍历这些样本的全部答案；验证始终包含全部可接受答案。
- 并列是有限续玩中的同分，不是等价性证明；0.5 是配置的训练权重，不是统计置信度。

## 验证与 checkpoint

checkpoint 使用固定验证集上每状态等权、无小分差降权的 `val_action_set_nll`：对可接受的完整 JSON 答案概率求和再取负对数。序列 log probability 使用全部回答 token 的和，包含模板结束符。

同时保存合法候选归一化集合概率、候选 argmax 集合命中率、教师估计后悔值、原单答案平均 token NLL、信念标签 CE，以及分组样本数和指标。无样本返回 null，缺少所选动作的教师得分时后悔值不可估计。候选命中率不等于自由生成合法率或对局胜率。

训练的答案轮换与 checkpoint 的集合 NLL 是不同目标；后者衡量可接受答案的总概率。旧目标的 checkpoint 和恢复进度在服务调用前拒绝。

## 本地检查结果

- 全量测试：**141 passed，86 subtests passed**。覆盖多答案轮换、降权及归一、集合概率手算、checkpoint 选择、恢复一致性、旧目标拒绝、数据保真、篡改检测和费用计数。
- 真实缓存 `Qwen/Qwen3.5-9B` tokenizer 和 Tinker SDK 数据类型：20,000 条样本、14,691 个可接受答案变体的模板、损失 mask 和长度检查通过。
- 验证集每 epoch 共 10,729 个合法候选序列，已全部分词检查。最长完整序列为 6,259 tokens，低于 16,384 上限。
- 修正了流水线提前连接服务的顺序：SFT 本地模板、长度和恢复检查先于服务初始化。独立代码复查未发现阻断问题。
