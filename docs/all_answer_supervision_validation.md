# 全部并列答案监督：本地验收记录

日期：2026-11-14。方法版本：`empirical_all_answers_weighted_actions_v2`。

所有并列答案现在在每次访问其状态时共同参与监督，每个答案分到状态有效权重的 `1/k`。保持 3 epochs、原逻辑 batch 和优化器步数。本次完成实现、数据准备、离线检查和费用估算；模型 API、模型 forward 和实际优化器调用均为 0，尚未执行付费训练。

## 训练方式

原始状态仍是采样单位，每个逻辑 batch 包含 16 个动作状态和 16 条信念样本。选定动作状态后，展开其全部可接受答案，在同一次梯度更新中计算损失。展开不增加状态采样次数、优化器步数，也不改变学习率计划。

设一个状态的有效权重为 w，有 k 个可接受答案，每个答案分到 w/k，再平分给其全部回答 token。状态总权重保持 w。小正分差样本的原始权重仍为 0.5，其他动作状态为 1；仅按训练动作集均值 0.924875 归一。信念标签权重始终为 1。加权求和得到的是每状态全部答案的平均 token NLL；验证仍以完整答案集合 NLL 选择 checkpoint。

答案顺序固定，状态 shuffle 使用原种子。中断恢复会重现状态次序、全部答案、权重及学习率。训练或恢复训练时，旧 v1 目标的配置、数据和 checkpoint 在创建服务会话前拒绝。旧数据目录及[旧验收记录](action_supervision_validation.md)保留。

## 实际数据与覆盖

新目录：`outputs/runs/selfplay_v2_20261113_01_quality_supervision_v2`。从原续玩复评目录 `selfplay_v2_20261113_01_quality` 生成；没有重跑教师续玩，也没有改动原观测、候选得分、单答案记录、信念标签或按完整对局的划分。

- 原数据仍为 10,000 个动作状态和 10,000 条信念样本。
- 训练集为 8,000 个动作状态、7,995 条信念样本。每轮信念循环补齐到 8,000 次访问。
- 每轮全部动作状态展开为 11,726 个答案，合计 19,726 条训练序列；这不是新增原始对局样本。
- 94 个有 4／5 个答案的训练状态，每次均包含全部答案。1,767 个双答案状态也在同一次访问中均等分摊权重，不再出现三轮中的 2∶1 监督次数。
- 每轮仍为 500 次优化器更新，三轮共 1,500 次。三轮动作状态访问 24,000 次，对应 35,178 条动作答案序列；信念访问 24,000 次。

## 验证结果

- 全量测试：**143 passed，88 subtests passed**。包括 4／5 答案全覆盖、双答案均分、状态权重守恒、动作和信念损失切分、原 batch／步数／学习率、恢复一致性、旧版本拒绝和费用口径。
- 独立代码复查未发现阻断问题，并独立通过 11 项训练相关测试。服务响应仅使用显式测试替身，不作为真实模型实验结果。
- 使用真实缓存 Qwen3.5-9B tokenizer 和 Tinker SDK 数据类型，检查全部 20,000 条样本和 14,691 个可接受答案变体。掩码、状态总权重、信念单位权重及长度全部通过。
- 验证集每轮 10,729 个合法答案序列全部分词检查；最长完整序列为 6,259 tokens，低于 16,384 上限。
- 训练动作名义总权重为 8,000；SDK float32 掩码实测总和为 7999.99984667，浮点误差在检查容差内。
- 独立检查脚本与流水线估算的 token、原状态访问数、展开序列数和优化器步数逐字段完全一致。费用集成测试还对照了测试替身实际收到的每次训练／验证请求。
